⏰ 复盘提醒

每天到点提醒你「该复盘了」。平板 APP 里是系统级通知——APP 关着、屏幕锁着也会响； 网页端需要允许浏览器通知，且页面开着才会弹。提醒时间是本机设置， 手机定 8 点、平板定 20 点互不影响。

多端同步（安卓平板 ⇄ 手机 ⇄ 电脑）

用你自己的一个 私有 GitHub 仓库当中转，不需要买服务器。 每台设备填同一个 Token 和同一个仓库名就会自动双向合并：错题按「最后修改时间较晚」的那端为准， 练习记录取并集；练习册的文字层也会同步，所以一台设备上传过的练习册， 在别的设备上直接就能浏览勾选导入，不用重新传一遍 PDF。 AI 接口（地址 / Key / 两个模型）和复习间隔也在同步范围内，所以各设备用同一个 AI、 跑同一套复习节奏 —— 代价是 Key 会以明文存在这个私有仓库里，保持它私有、别加协作者。 只有两样东西不同步：GitHub Token 和仓库名（要读到云端就得先有它们，鸡生蛋）， 靠下面的「发给手机 / 平板」传递；以及 PDF 原文件本身（几十上百 MB， 但真正用得上的文字层已经同步了）。
开着就不用管同步这件事：改完 4 秒自动上传，每 3 分钟自动拉一次别的设备的改动， 断网恢复、切回页面、切走页面前都会各补一次。顶栏那个小胶囊显示当前状态， 觉得不及时点它一下就是立刻同步。页面在后台时不做定时拉取，所以挂着也不耗电耗流量。

发给手机 / 平板

在这台电脑上把上面的接口和同步都填好、点过「保存」之后，用这个按钮导出一份 已经带着配置的副本，把那个文件传到手机和平板上直接打开就能用， 不用在每台设备上再填一次 Token。
⚠ 导出的那个文件里写着你的 API Key 和 GitHub Token。只发给自己的设备， 不要放到公开网页或分享给别人。要公开发布就用原始文件（配置为空的那份）。
另一条路：配置码。在手机上打开没配置的原始文件，把这串码粘进去点应用， 效果和上面那份带配置的副本一样，而且手机上不用打那一长串 Token。
⚠ 同步的是错题 + 练习册文字层（题号、题干文字）。PDF 原文件几十上百 MB，不上传， 只留在上传它的那台设备上；扫描版练习册需要看图识别时，得在有原文件的设备上做。 Token 存在本机浏览器里，别在公用电脑上填。
